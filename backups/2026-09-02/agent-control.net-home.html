How it works

Four steps. No custody. The agent cannot skip the check if you wire it in front of every send.

  1. 01

    Enroll a wallet

    Paste a live address. We pull native balance and recent on-chain transfers.

  2. 02

    Set policy

    Cap daily spend, restrict destinations, set hourly velocity.

  3. 03

    Wire the hook

    Give the agent its API key. It MUST POST /api/v1/check before every send.

  4. 04

    Watch + pause

    On-chain sync and pre-sign decisions land in one feed. Pause from the console.
